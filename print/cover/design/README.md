# Cover design

Source for the cover built in Claude Design:
https://claude.ai/artifact/7XQvkUvNmuqbjLcENr1tDV

- `Main.dc.html`: full casewrap spread (back, spine, front). It imports
  `BackPanel.dc.html` and `FrontPanel.dc.html` (6 × 9 in each).
- `canvas.json`: canvas layout.
- `locket.svg`: the engraved locket, generated by `locket.py`.

The `/_blob/...` URLs point to assets uploaded to the canvas: the two
Sorts Mill Goudy fonts from `print/fonts/` and
`print/book/images/alice-and-john.jpg`. These files render only inside
the canvas; export the PDF from there.

**Size is an estimate** (285 pp, spine ≈ 0.94 in, 0.75 in wrap →
14.44 × 10.5 in). Replace with the numbers from Lulu's cover template
before exporting.
