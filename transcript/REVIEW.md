# Review queue — CLOSED (all items resolved)

Pages where the Phase 2 verification pass confirmed the transcript was as
accurate as it could be made from the photo alone, but a genuine ambiguity
remained that only the physical manuscript page could resolve.

**Phase 2 completed 2026-07-07: all 288 pages verified** (33-page pilot
plus nine further batches). **The review queue itself was then worked to
zero (2026-07-08) in a physical-page review with the author's
great-grandson**: every queued ambiguity was checked against the physical
manuscript and resolved in the corresponding transcript file (see each
page's "Resolved:" transcriber note). The final two items — the erased
title blocks on pages 1 (Book I) and 165 (Book II) — were closed as
**permanently unrecoverable**: physical recovery was attempted (reading
from the back of the sheet, at all angles) without success, and the
physical pages are no longer accessible. The reading edition will carry
editor-composed titles, disclosed in the foreword as the edition's one
truly editorial invention (see book/edits.md).

Along the way, verification also caught and fixed a number of Phase 1
errors unrelated to physical ambiguity — most notably several places
where an authorial typo had been silently "corrected" back to standard
spelling (a violation of the archival verbatim principle, now fixed in
each case) and two page photos (224, 226) that were still upside down
despite the Phase 0 orientation pass. See the per-page Transcriber notes
for full detail on any fix.

The batch-by-batch process notes below are kept as a historical record of
cross-page patterns discovered during verification.

Added from batch 2 (pages 2–34, verified 2026-07-06). This batch also
surfaced a recurring **blue-pencil correction habit** — several marks
below, plus page 210 above, were originally filed as ordinary typewriter
strikeovers but turned out under color analysis to be a distinct blue
pencil/ink. Worth watching for specifically in later batches.


Added from batch 3 (pages 35–69, verified 2026-07-06). The blue-pencil
pattern above continued to turn up regularly in this batch (pages 36, 41,
44, 52, 59 — bringing the running total to 9 confirmed instances); several
other candidate marks were checked against the same color signature and
correctly ruled back out as ordinary typewriter ink, so not everything
struck-through is pencil.


Added from batch 4 (pages 70–99, verified 2026-07-06). Four more confirmed
blue-pencil instances this batch (pages 71, 79, 80, 99), bringing the
running total to 13. One page-68-style false alarm was also caught and
reverted this batch: an earlier pass misread "take" as "tako" on page 94
based on an ambiguous letter shape; a closer look (prompted by a user
spot-check) showed this typewriter's lowercase "a" renders as a solid,
nearly-closed blob indistinguishable from "o," so the shape alone wasn't
good evidence — "take" was restored. Noting this as a reminder that
verification passes can introduce errors, not just catch them.


Added from batch 5 (pages 101–132, verified 2026-07-06). This batch's most
notable finding wasn't a pencil mark: a systematic quote-mark pattern
emerged on pages 130–132, where the typist used a single quote (') to
resume or close dialogue mid-paragraph after an action beat like "he
said," and Phase 1 had smoothed several of these to double quotes (4
instances corrected). This is a distinct failure mode from the word-level
typo smoothing found earlier, and may be worth a dedicated sweep across
the rest of the manuscript later.


Added from batch 6 (pages 133–164, verified 2026-07-06/07). This batch
completes verification of all of Book I. The quote-mark pattern from
batch 5 continued to show up regularly (pages 138, 140, 156, plus a
closing-quote variant, not just opening/resuming), and a dropped comma on
page 144 added another sacred-layer restoration.


Added from batch 7 (pages 166–198, verified 2026-07-07) — the first batch
into Book II. Two notable discoveries this batch, beyond the usual open
items: (1) a systematic pencil-correction pattern where "Johnie" is
consistently corrected to "Johnnie" (added second n) across pages
176–179, suggesting a deliberate later pass through the manuscript to fix
this character's name — worth watching for on any other page featuring
him; (2) a possible misclassification on **page 231** (already verified
in an earlier batch, outside this one's scope) where its "Johnnie" mark
was called an ordinary typewriter double-strike, but color-sampling
elsewhere in this batch suggests it may actually be the same pencil
correction — worth a second look when convenient, not urgent.


Added from batch 8 (pages 199–229, verified 2026-07-07). Two of Book II's
photos turned out to still be upside down despite the Phase 0
orientation pass — **pages 224 and 226** — both caught by verification
agents reading the image and finding it didn't match the transcript's
described layout; both corrected in place, text was already accurate
against the corrected orientation.


Added from batch 9 (pages 230–262, verified 2026-07-07). A poem-formatting
bug was fixed on page 232 (Phase 1 had split a continuous 4-line Rubaiyat
quotation with spurious blank lines) — worth checking other quoted-verse
pages for the same issue. Several previously-unflagged overtyped letters
were also found and marked on pages 240, 245, and 249.
